# 🛒 বাজার দর (BazarDor)

> **Know the price. Compare the market.**

BazarDor is a responsive web application that helps users explore daily product prices in Bangladesh, compare prices across available markets, and understand price changes.

---

## 🛠️ Technologies Used

**Next.js** · **React** · **TypeScript** · **Tailwind CSS** · **REST API** · **Better Auth** · **MongoDB**

---

## ✨ Key Features

| **#** | **Feature** | **Description** |
|:---:|---|---|
| **01** | 🛍️ **Product Prices** | Explore daily prices of different products. |
| **02** | 🏪 **Market Comparison** | Compare prices across available markets. |
| **03** | 📈 **Price Changes** | Check whether prices have increased, decreased, or remained unchanged. |
| **04** | 🗂️ **Product Categories** | Browse products by category. |
| **05** | 👤 **User Authentication** | Create an account, sign in, and access profile features. |

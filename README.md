# 🛒 বাজার দর (BAZARDOR)

> **Know the price. Compare the market.**

BazarDor is a responsive market-price application that helps users explore daily product prices in Bangladesh, compare prices across markets, and understand price changes.

---

## 🛠️ Technologies Used

**Next.js** · **React** · **TypeScript** · **Tailwind CSS** · **REST API** · **Better Auth** · **MongoDB**

---

## ✨ Key Features

| **#** | **Feature** | **Description** |
|:---:|---|---|
| **01** | 🛍️ **Product Listing** | Browse products and explore their daily prices. |
| **02** | 📊 **Price Comparison** | Compare minimum, maximum, and average prices across available markets. |
| **03** | 📈 **Price Changes** | Check whether prices have increased, decreased, or remained unchanged. |
| **04** | 🗂️ **Product Categories** | Browse products by category to find relevant items. |
| **05** | 🔎 **Product Details** | View individual product information, pricing, and market comparisons. |
| **06** | 📉 **Price Summary** | Review minimum, maximum, and average prices at a glance. |
| **07** | 🔐 **User Authentication** | Sign up and sign in using the available authentication options. |
| **08** | 👤 **User Profile** | Access your profile and account information. |
| **09** | 📱 **Responsive Design** | Browse the application on mobile, tablet, and desktop devices. |
| **10** | ⏳ **Loading & Error States** | Get visual feedback while content loads or when a page is unavailable. |
